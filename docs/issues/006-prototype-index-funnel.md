# Issue 006: Prototype Index For Tailscale Funnel

## Goal

Create a small public-facing web entrypoint for sharing MVP prototypes with friends and family.

## Scope

- Add an MVP index page.
- List available prototypes.
- Include short public-facing descriptions.
- Include current status.
- Include what to try.
- Link into the Continuum prototype.
- Make it suitable for exposure through Tailscale Funnel.

## Acceptance Criteria

- [x] A single local server can serve the index and Continuum prototype.
- [x] Index has a lightweight showcase/lab feel.
- [x] Continuum listing includes intended use: alone in a quiet place.
- [x] Description avoids overpromising AI context features not built yet.
- [x] Index includes a small blog/build-notes section.

## Out Of Scope

- Marketing site.
- Analytics.
- Admin UI.
- Public signup growth funnel.
- Multi-tenant product positioning.
