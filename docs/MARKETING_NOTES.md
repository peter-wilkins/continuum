# Marketing Notes

## Core emotional problem

Current AI chat systems create continuity anxiety.

Users often feel:

> "I know I already thought about this, but I don't know where it lives anymore."

Continuum positions itself around continuity of thought rather than generic AI conversation.

---

## Product framing

Chat systems help people think.

Continuum helps people continue thinking.

---

## Core tagline

> The system should adapt to the user faster than the user adapts to the system.

---

## Emotional positioning

Continuum should feel:

- calm
- grounded
- lightweight
- continuous
- trustworthy
- momentum-restoring

not:

- noisy
- productivity-heavy
- dashboard-centric
- cognitively demanding

---

## Sci-fi promotional direction

Early creative direction:

- ship computer
- continuity collapse
- thought stream instability
- cognitive exhaust
- contextual recovery
- memory restoration

Example line:

> "Captain, the thought stream's collapsing!"

Potential positioning:

Continuum as a continuity engine for human cognition.
