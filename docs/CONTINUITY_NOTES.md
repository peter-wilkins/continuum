# Continuity Notes

Continuum should focus on preserving and restoring useful context over time.

Key principles:

- Store raw entries in an append-only log.
- Keep original source material recoverable.
- Let AI summaries and annotations sit above the source log.
- Retrieve contexts, not only transcripts.
- Help users resume a thread of thought quickly.
- Reduce the need to scroll through old chats.
- Avoid fragmenting thinking into isolated sessions.

Core idea:

The unit of storage is events.
The unit of retrieval is context.

Success metric:

How quickly can the user re-enter the relevant context and continue thinking?
